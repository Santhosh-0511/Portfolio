# P Santhosh Sri Sai Ram — Developer Portfolio

An interactive, dark sapphire HUD developer portfolio for **P Santhosh Sri Sai Ram** (Computer Science undergraduate at **IIIT Lucknow**, LeetCode Knight, Codeforces Specialist).

Inspired by modern tactical engineering aesthetics, high-performance web architecture, and clean minimalism.

## Tech Stack & Architecture

- **Core**: React 18 + TypeScript + Vite
- **Styling**: Vanilla CSS Design System with Dark Sapphire tokens, glassmorphism, and tactical HUD elements
- **Interactive Visuals**: Aerodynamic fluid custom cursor with velocity-based inertia, stardust particle trail, and interactive state feedback
- **Fluid Ambient Canvas**: Proximity constellation particle field responding to cursor gravity
- **Icons**: Lucide React
- **Keyboard Navigation**: Global Command Palette (`⌘K` / `Ctrl+K`)

## Features & Highlights

- **Hero & Typewriter**: Dynamic role typewriter, real-time IIIT Lucknow status badge, concise bio, and instant verified links (GitHub, LinkedIn, Email).
- **Interactive Terminal & About**: Interactive Unix-style terminal emulator (`whoami`, `projects`, `cp`, `skills`) and personal journey narrative.
- **Academic Profile & Education**: Detailed records of B.Tech CSE at IIIT Lucknow, coursework tags, and leadership in Goonj The Dramatics Society.
- **Competitive Coding Arena**: Verified badges and ratings for LeetCode Knight (1945), Codeforces Specialist (1425), CodeChef 3-Star (1618), global contest ranks, and Hacktoberfest 2025 SuperContributor.
- **Production Engineering Projects**:
  - **Road-Sense**: Real-time driver fatigue & seatbelt detection with OpenCV, YOLOv8, route planning, and low-latency inference load-tested for 1,000 concurrent users.
  - **Medi Share**: Pharmaceutical redistribution platform with Google Gemini & OCR.space text extraction (>90% accuracy), role-based routing, and PostgreSQL APIs.
- **Capabilities Matrix**: Interactive category filtering for Languages, AI/ML, Backend, Frontend, Cloud/Databases, and Tools.
- **Tactical Contact Dispatcher**: Direct transmission composer, 1-click email copy to clipboard, and instant verified links.

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
